# Молва

Монолитная платформа доверительных обращений: Go, PostgreSQL, Redis и React.

## Как поднять сервис

Нужен запущенный Docker Desktop. В каталоге проекта выполните:

```bash
cp .env.example .env
./scripts/up.sh
python3 scripts/seed_demo.py
```

Скрипт можно запускать из любой директории. Он не зависит от абсолютного пути
проекта и обходит ошибку Docker Desktop при сборке из каталогов с кириллицей.

Остановить сервис с сохранением базы:

```bash
./scripts/down.sh
```

Уже открытая вкладка не закрывается вместе с сервером. Обновите её: после
остановки браузер должен показать ошибку подключения.

Остановить сервис и удалить базу:

```bash
./scripts/down.sh -v
```

- сайт заявителя: http://localhost:8088
- кабинет сотрудников: http://localhost:8089
- логины: `admin@molva.local`, `operator@molva.local`, `expert@molva.local`
- пароль локального демо: `Molva-local-2026!`

Перед публикацией замените `TOKEN_PEPPER` и `STAFF_BOOTSTRAP_PASSWORD` в `.env`.

Чтобы полностью очистить базу и создать её заново:

```bash
./scripts/down.sh -v
./scripts/up.sh
python3 scripts/seed_demo.py
```

## Как работать с сервисом

Заявитель выбирает, от чьего имени обращается, отвечает на настраиваемый опросник, описывает ситуацию и при желании оставляет email. После отправки нужно сохранить единый код доступа. По нему доступны чат, изображения, завершение, возобновление и удаление обращения.

Оператор входит во внутренний кабинет, уточняет детали до назначения эксперта, меняет приоритет и назначает исполнителя. После назначения оператор больше не пишет в чат. Эксперт видит только назначенные обращения, общается с заявителем, прикладывает изображения, ведёт внутренние заметки и меняет статус. Администратор управляет сотрудниками, маршрутизацией, опросником, аналитикой и журналом действий.

При кризисных словах интерфейс показывает номера детского телефона доверия `8 (800) 2000-122`, `124` с мобильного и `112` при непосредственной опасности.

Коды доступа к демонстрационным обращениям после наполнения сохраняются в `demo-access-codes.json`.
